  # 🏧 Caixa Eletrônico em Python (POO)

    Sistema bancário simples em linha de comando (CLI) desenvolvido em Python para praticar 
    Programação Orientada a Objetos (POO).

    ## 📋 Funcionalidades

    - Cadastrar clientes (nome e CPF)
    - Criar **Conta Corrente** (com limite de cheque especial de R$ 500,00) e **Conta Poupança**
    - Depositar valores
    - Sacar valores (com validação de saldo e exceções customizadas)
    - Consultar extrato com data e hora das transações

    ## 📁 Estrutura do Projeto


    caixa-eletronico-tonjr/
    ├── tonjr_entidades/        # Classes Cliente, Conta, ContaCorrente e ContaPoupanca
    ├── tonjr_operacoes/        # Classe Banco
    ├── tonjr_utilitarios/      # Exceções customizadas
    ├── tonjr_mini_projeto.py   # Arquivo principal (menu CLI)
    ├── LEIAME.txt
    └── .gitignore
   

    ## 🚀 Como Executar

    Pré-requisito: **Python 3** instalado (não precisa instalar bibliotecas externas).

   
    git clone https://github.com/Tonjr12/caixa-eletronico-tonjr.git
    cd caixa-eletronico-tonjr
    python tonjr_mini_projeto.py
